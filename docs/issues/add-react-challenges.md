### Subject: Add React-specific coding challenges

### Description:

We need to expand our challenge offerings to include challenges specifically focused on React development. This will cater to users learning or specializing in React and provide relevant practice.

**Potential Challenge Areas:**
- Component creation and state management.
- Hooks (useState, useEffect, useContext, etc.).
- Routing with React Router or Next.js.
- API fetching and data display.
- Form handling and validation.
- Testing React components.

**Target areas:**
- `src/collections/Challenges.ts` (to define challenge structure)
- `src/core/challenges/` (for challenge logic and types)
- `src/app/(frontend)/challenges/` (for UI components and pages)
- `src/components/SolutionEditor/` (to adapt editor for React)

### Why is this needed?

Adding React challenges will attract and engage a significant portion of developers who are focused on frontend development and the React ecosystem, making the platform more comprehensive.
