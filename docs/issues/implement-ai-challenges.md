### Subject: Implement AI-generated challenges

### Description:

We should explore and implement the functionality to generate coding challenges using Artificial Intelligence. This would allow for a more dynamic and potentially personalized set of challenges for users.

**Potential Features:**
- Define parameters for AI challenge generation (e.g., difficulty, topics, language).
- Integrate with an AI model API.
- Store and manage generated challenges.
- Potentially allow user feedback on AI-generated challenges.

**Target areas:**
- `src/core/challenges/` (for core logic)
- `src/app/(payload)/api/` (for API endpoints)
- Relevant UI components for configuration and display.

### Why is this needed?

Implementing AI-generated challenges can significantly increase the variety and quantity of challenges available on the platform, keeping content fresh and potentially tailoring it better to individual user needs and skill levels.
