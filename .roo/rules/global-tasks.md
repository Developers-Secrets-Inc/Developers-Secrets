- **Centralisation des tâches**
  - Toutes les tâches générales du projet doivent être ajoutées dans le fichier [global.md](mdc:docs/tasks/global.md).
  - Ce fichier sert de source unique de vérité pour le suivi des tâches à l'échelle du projet.

- **Format recommandé**
  - Utiliser la syntaxe Markdown pour les listes de tâches :
    ```markdown
    - [ ] Tâche à faire
    - [x] Tâche terminée
    ```
  - Organiser si besoin par sections : À faire, En cours, Terminé, etc.

- **Mise à jour automatisée**
  - Lorsqu'une tâche est demandée via l'IA, elle doit être ajoutée automatiquement à ce fichier, sauf indication contraire.

- **Bonnes pratiques**
  - Préciser le contexte, la priorité ou le responsable si pertinent.
  - Garder l'historique des tâches terminées pour le suivi.

- **Références**
  - Voir la structure actuelle dans [global.md](mdc:docs/tasks/global.md)
  - S'inspirer des conventions de gestion de tâches Markdown (cases à cocher, sections, etc.)
